# ADR 002：首轮基准与证据边界

状态：采用；正式效果评测尚未完成。

固定 Click 8.1.8 与 HTTPX 0.28.1，完整 SHA、源码目录和环境路径见
`benchmarks/manifests/repositories.json`。首轮使用 Python 3.12.13；独立环境的实际依赖清单由
`benchmarks/runners/probe.py` 保存。Git tag 只用于定位，重放必须校验固定 commit。

首批 12 条任务为开发试验集：6 条公开仓库可控变异，6 条自建 fixture。覆盖边界回归、环境变量切分、
文档变化、删除、重命名、动态调用、模块级变化与继承。它们全部为 `annotation_status=unreviewed`，
描述的是待复核假设，不能称为金标、独立测试集或计算准确率。没有真实历史缺陷标签，也不声称任务代表生产分布。

机器测量分别保存准备结果与解析增量一致性。增量采用 base 解析缓存并全局重新解析引用，比较同一 head 的
规范化 hash，记录耗时、复用文件数、未知调用和诊断数。单次耗时没有重复试验或显著性，不能推广成稳定加速比。
此试验不覆盖 Dense/Reranker 索引原子发布，也不是 B1～B4 质量对照。

当前 Docker 不可用。允许在 `artifacts/environments/` 的独立虚拟环境收集两个可信公开仓库测试，
作为 M0 开发环境探针。此操作不构成产品隔离执行验收；产品必须继续在 Docker 不可用时显式拒绝执行。
不会对用户项目运行测试安装脚本。公开仓库克隆、变异副本与大日志均放入忽略的 `artifacts/`。

正式评测仍需人工复核、扩大到计划约定样本规模、冻结分组、采集版本绑定覆盖，并完成强混合检索、无图、
无覆盖和同预算 Agent 对照。未完成部分保留为未完成，不能用这些开发探针代替。
