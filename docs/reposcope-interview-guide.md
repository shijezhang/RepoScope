# RepoScope 面试说明

## 两分钟

RepoScope面向Python代码变更评审：输入两个固定commit，输出变更符号、潜在调用方、测试计划及可核查源码/执行证据。核心不是整仓聊天，而是让版本、图路径与测试结果保持一致。用AST做有限解析，以双侧diff保留删除符号；无法证明的动态调用保留未知，测试覆盖不足时全套回退。当前两个公开仓库已完成收集和回归探针，12条开发变异通过解析增量一致性；强检索可运行性及容器实机已验证，正式质量基线与Agent收益仍待验证。

## 十分钟

依次演示 [demo.md](demo.md)：真实Click变化、base/head源码、原有测试的回归探针，再展示动态调用未知与环境不足历史的显式重试。随后解释Symbol ID与内容hash、删除用base图、candidate调用和报告revision。最后展示机器结果文件和未完成项，明确本地探针不是容器成功记录。

## 三十分钟

在十分钟路线之后，展开 `parser.py` 的作用域和重导出反例、`impact.py` 的连续路径、`runner.py` 的先记录后提交、`worker.py` 的过期执行回收。展示全量/解析增量hash与实际耗时，讨论为何缓存不一定更快。以强基线/消融设计结束，不给尚未得到的效果数字。

## 常见追问

1. **为什么不用文本搜索？** diff能准确给出变化位置，文本检索未必发现没有共同词的跨模块调用方。但图也会扩散误报，必须用B1/B2实验验证价值；本轮未给收益结论。
2. **图可达为何不等于影响？** 分支、参数、动态分派可能使该路径不执行。图只证明静态关系，测试失败才提供具体观察。
3. **动态调用怎么办？** unknown/candidate可见，覆盖补充或全套回退。未实现完整Python类型推断。
4. **为什么AST？** 单语言、源码位置足够、无需导入代码。代价是自建有限解析且需要很多作用域反例；Tree-sitter可扩多语言但也不自动获得准确调用图。
5. **删除/重命名？** 双侧行区间分别映射，删除从base入边追踪；内容/名称匹配只是明确映射证据，Git未识别rename时退删除+新增。
6. **覆盖过期？** 绑定源码快照、套件、环境和配置hash；base覆盖仅做head线索。fixture/配置更改保守扩大测试范围。
7. **固定流程足够吗？** 明确diff通常足够。Agent默认补查疑点，明确授权时可选择一次验证；未有实验收益前不强制开启，更不把工具数量当能力。
8. **版本一致性？** API队列保存SHA，源码来自Git object；证据检查hash，测试checkout验证tree；不读用户工作区修改。
9. **如何防评测泄漏？** 在线选择仅消费base覆盖、head代码和collected池，不读取head全套失败集合；当前12条未复核开发case不冒充holdout。
10. **增量如何正确？** 只缓存文件AST，全部引用重解，比较同head的规范化结果。缓存不等于最小失效，也没有向量增量完成声明。
11. **全套更快怎么办？** 直接跑全套，产品价值转向定位/解释。Click小pool的环境探针已说明不能靠缩减数量掩盖分析开销。
12. **原创在哪里？** 版本和证据契约、具体解析/影响实现与可靠执行协调。图、RRF与coverage不是原创算法。

## 术语

| 术语 | 含义 |
|---|---|
| Snapshot | 固定commit、tree与解析版本绑定的源码分析对象 |
| resolved/candidate/unresolved | 静态解析证据等级，不是校准概率 |
| Impact | 应进一步检查的潜在影响集合，非完整行为真值 |
| nodeid | pytest实际收集的测试标识，包含参数化后缀 |
| context | coverage记录的执行归属，本项目保留setup/call/teardown |
| Evidence | 固定快照源码或运行事实，拥有可验证位置/身份 |
| Revision | 同一运行报告的不可变历史版本 |
| Parse incremental | 复用未变AST并重解关系，非端到端检索增量 |

## 可使用的简历措辞

> 构建Python代码变更分析工作台，将Git固定快照、有限AST调用图、双侧diff与源码证据校验连接到CLI/Web报告；实现任务幂等、版本绑定覆盖和Docker测试执行接口。
>
> 在Click/HTTPX固定版本完成测试收集与可控回归探针，在12条未复核开发变异上验证全量与解析增量规范化结果一致；保留动态调用、未知项与执行环境缺失状态。

不要使用尚无实验支持的召回提升、测试节省、Agent收益、生产上线或正式120条评测完成描述。
